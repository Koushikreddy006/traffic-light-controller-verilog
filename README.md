# Traffic Light Controller using Verilog HDL

## Overview
This project implements a simple Traffic Light Controller using Verilog HDL and Finite State Machine (FSM) concepts.

The controller changes traffic lights in the following sequence:
- Red
- Green
- Yellow

The design is simulated and verified using a Verilog testbench.

---

## Features
- FSM-based traffic light control
- Clock-driven state transitions
- Reset functionality
- Simple RTL design
- Testbench verification

---
